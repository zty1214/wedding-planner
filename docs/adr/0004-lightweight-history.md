# 用回收站与定期快照替代逐操作完整历史

频繁拖动和布局微调不值得每次保存一个历史版本。使用者选择自动同步当前状态、删除回收站、手动命名版本、每日快照及按日活动热力图：常规编辑只更新当前数据和日汇总，删除保留恢复材料，批量覆盖或整项目恢复前额外保留安全快照。

接受普通字段无法日内逐次回溯的取舍，以减少历史膨胀及维护复杂度。活动计数不依赖完整操作日志；快照和回收站保留所需图片引用，恢复不得静默覆盖后续安排。回收站保留 30 天，自动每日快照保留 90 天，手动命名版本不自动删除；普通协作链接允许恢复回收站，整项目恢复需独立私有管理链接。业务历史不替代独立灾难备份。

每日版本对应活跃日最后已提交的业务状态，由服务端日结固定版本；定时任务延迟时，跨日首次写入先完成前日封存。接受这一步短暂等待，其事务能力、延迟和故障恢复在开发初期验证。整项目恢复不回滚历史目录与活动汇总；旧代次回收材料仍可预览/导出，但首期不支持直接跨代次恢复。
