# 用项目分享链接授权，首期不建立成员管理

产品只服务少量备婚朋友及可信家人，日常通过转发链接协作。使用者选择持有效长随机分享凭证即可查看和编辑对应项目，替代匿名会话绑定成员、逐人角色和邀请审批，以减少跨设备加入和权限恢复的负担。

接受链接转发即授权、不能可靠识别真人、无法单独取消某位持有者的代价；泄露时轮换凭证，使旧凭证及派生会话失效。稳定项目 ID 与可轮换凭证分离，数据库仍拒绝浏览器直写，服务端逐次校验项目权限；创建者保管独立私有管理链接，用于轮换协作链接和整项目恢复；普通协作链接不能执行这些操作。两类凭证均遗失时通过受控人工流程找回，不引入成员管理。
