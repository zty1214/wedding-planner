# 保留 Planner 产品基础，将数据平台统一到 CloudBase

沿用融合方案中已经确认的决策：以 wedding-planner 为唯一主仓库，保留四个页面、现有交互方向和 Konva 画布，将数据平台统一到 CloudBase，选择性吸收 wedding_project 的领域规则与验证能力。这样可以保留实际使用者熟悉的完整流程，同时改善保存与协作；选择 CloudBase 不要求搬迁到来源仓库的页面架构。

本决定不代表迁移、发布或平台权限已验证完成。已确认的草稿、双链接授权和轻量历史分别见 ADR 0002–0004；工程验证与验收以融合方案为准。
